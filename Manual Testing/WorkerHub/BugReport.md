# WorkerHub – Bug Report

This document contains the defects identified during manual testing of the WorkerHub application.

| Bug ID | Module | Summary | Severity | Priority | Status |
|--------|---------|---------|----------|----------|--------|
| BUG_001 | Registration | Duplicate phone number validation was missing during user registration. | High | High | Fixed |
| BUG_002 | Login | Username field accepted input beyond the maximum allowed length. | Medium | High | Fixed |
| BUG_003 | Job Application | Worker was able to apply for the same job multiple times. | High | High | Fixed |
| BUG_004 | Notifications | Notification was not generated after successful application acceptance. | Medium | Medium | Fixed |
| BUG_005 | Profile | Updated profile changes were not reflected immediately after saving. | Low | Medium | Fixed |
